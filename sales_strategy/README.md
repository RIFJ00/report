# 政策リサーチ 営業アプローチ自動作成 v1.53

## Web展開構成
このフォルダは、従来の v1.51 と同じ分離ファイル構成で、そのまま GitHub Pages 等へ配置できる。

- `index.html` : Web画面本体
- `styles.css` : 画面スタイル
- `app.js` : 営業文面生成・進捗管理ロジック
- `data.js` : ブラウザ読込用企業マスタ（387社）
- `active_master.json` : v1.53 現行企業マスタ（387社）
- `archive.json` : アーカイブ企業
- `company_rename_map.json` : 企業名表記揺れ・旧名称変換
- `政策リサーチ_営業アプローチ自動作成_v1_52.html` : 単体HTML版

## v1.53 の表示仕様
- 「主業種・戦略分野」は営業で一目で確認できる短いポイント表示。
- 「最初に刺すテーマ」も短い営業ポイント表示。
- 詳細な業種・政策接点・テーマ説明は、選択企業の右側詳細欄（企業説明）へ表示。
- `検索用分野タグ`、`副テーマ` は検索・絞り込み用の詳細データとして保持。

## GitHub Pages
ZIPを展開し、このファイル群をリポジトリの公開対象ディレクトリ直下へ置く。`index.html` と `data.js` / `app.js` / `styles.css` の相対位置を変更しないこと。

## v1.53 旧縁と初回営業トークの更新
- 企業マスタA列○による「旧縁あり」自動判定は維持。
- 「秘書経験には触れない」チェックボックスを廃止し、旧縁ありは政策秘書経験を含める。
- 旧縁なしは指定文面に変更（政策秘書経験、10年以上、継続150社前後・累計400社超）。
- 共通部分は「最初に刺すテーマ」を自動挿入、関連政府資料2～3件の説明を提案。
- GitHub Pages用と単体HTMLの両方に反映。
- 既存企業マスタおよびFirebase関連フィールドは維持。
