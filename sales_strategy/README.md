# 政策リサーチ 営業アプローチ自動作成 v1.2

## 主な変更
- 企業マスタを100社から400社へ拡張
- 100社の完全新規候補に加え、過去有料・トライアル・一部現在利用の履歴を統合
- 営業区分ごとに文面を自動切替
  - 完全新規：通常の新規アプローチ
  - 過去有料：再アプローチ
  - トライアルのみ：再トライアル
  - 現在利用：新規営業対象外
- 「初回メール」と「メール送付後フォロー」を統合
  - まず電話
  - 電話内容を反映したメールを同日送付
  - 反応がなければ2～3営業日後に再電話
- 機能していなかったコピーアイコン／コピー操作を撤去
- 公開連絡先、連絡先種別、確認レベル、公式URL、根拠URLを表示
- 電話で確認した担当者名・相手の課題をメールへ自動反映
- 10日間無料トライアルは従来方針を維持

## 利用方法
単体HTML版をブラウザで開き、会社名を入力または候補から選択してください。
未登録企業は自由入力し、業種を選択すると基本部署・テーマ・デモ内容を設定します。

## 注意
政策トリガーは営業直前に最新の政府会議、予算、制度、法改正、公募等へ更新してください。
公開連絡先は確認済み情報だけを表示し、未確認情報は推測しません。

## v1.14 端末への永続保存強化
- 営業進捗・スタンプ・営業メモ／履歴を同じ端末・同じブラウザに保存
- IndexedDBを主保存先として使用し、localStorageにも二重保存
- 再読み込み時にIndexedDBとlocalStorageを自動照合し、最新履歴を復元
- ブラウザが対応している場合は Storage Persistence API で永続保存を要求
- 日付変更と営業メモ入力は自動保存
- 保存状態を画面に表示
- 「営業メモ・履歴」を企業ごとに追加
- 営業進捗CSV・企業CSVにも営業メモ・履歴を出力
- JSONバックアップの書き出しに加え、JSONからの復元を追加

注意：
- ブラウザの「サイトデータを消去」や端末初期化を行うと保存データが消える可能性があります。
- HTMLファイルを別ブラウザで開いた場合は別の保存領域になります。
- 定期的な「進捗JSONバックアップ」の保存を推奨します。
