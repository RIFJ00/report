# ショート動画＆小説プロジェクト ソースコード

2026-10-19 名称更新版。文章作品対応・16分野80名の作家を収録。

## ファイル
- index.html：開始・設定・確認・結果画面
- style.css：レスポンシブデザイン
- app.js：設定操作・入力検証・コピー・テキスト保存
- authors.js：作家80名とジャンル・一般的な作風の特徴
- prompt.js：設定に応じた制作依頼文の生成

## 起動
ZIPを展開し、index.htmlをブラウザで開いてください。
ローカルサーバーを使う場合、Python 3のある端末で展開したフォルダーへ移動し、以下を実行します。

    python3 -m http.server 8000

ブラウザで http://localhost:8000 を開きます。
コピー操作が使えない環境では、選択された文章を手動でコピーしてください。
ビルド・npm・APIキーは不要です。Google Fontsが利用できない場合は代替フォントで表示します。

## 使い方
開始 → 完成形式・作品の種類・題材・作家などを設定 → 確認 → 依頼文をコピー → ChatGPTへ送信。
映像の場合のみGrokかGoogle Vidsを選択します。
中編・長編は文字数と章構成を指定できます。
このコードは依頼文作成フォームです。AIによる本文生成・画像生成・動画生成のAPIは接続していません。

## 設置
5つのHTML/CSS/JSファイルを同じフォルダーに置いたまま静的Webホスティングへ配置できます。
配布版に元サイトの認証・ホスティング設定は含めていません。公開先のアクセス制限は別途設定してください。
