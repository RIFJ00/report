# ショート動画＆小説プロジェクト v1.5.2

v1.5.3では、文章作品の参考作家を135名へ、ショート動画のアニメーション表現リファレンスを41名へ拡充しました。Word成果物のデフォルトは「小説・縦書き12pt・本文重視（12point.docx）」に変更しています。動画の約3分デフォルト、すべてクリア、10種類のWordテンプレートライブラリは継続して利用できます。

## v1.5.2の追加・変更

- ショート動画の完成尺のデフォルトを **約3分** に変更。
- 場面数のデフォルトは従来どおり **12場面**。
- 設定・確認・依頼文作成後の各画面に **「すべてクリア」** を配置。
- クリア時は入力値、検索／絞り込み、作家・アニメーター選択、制作ツール、Wordテンプレート選択、セッション追加DOCX、確認済みデータ、生成済み依頼文、ステータスメッセージを初期化。
- クリア後は設定画面へ戻り、動画は「約3分」の初期値から再開。

- 国内21名・海外20名、計41名のアニメーター／アニメーション作家を登録。
- 表現ジャンル、国内／海外、名前検索で絞り込み可能。
- 「指定しない／映像表現に合わせておまかせ」も選択可能。
- 任意のアニメーター名・表現名と、一般的な映像特徴を自由入力可能。
- 選択内容は確認画面と制作依頼文へ反映。
- 固有の画風や既存作品をそのまま再現する指示にはせず、動き、構図、光、色、編集、素材感などの一般化した映像特徴へ変換。
- Grok／Google Vids向けの実際の画像・動画生成プロンプトには、原則としてアニメーター名を直接書かず、一般化した特徴を使うよう固定。

登録データは `animators.js` に分離しているため、後から候補の追加・修正ができます。

## 登録テンプレート

1. 小説・縦書き11pt・挿絵あり（既存・検証済み）
2. 小説・縦書き12pt・本文重視（既存・検証済み）
3. 短編小説向け・コンパクト版
4. 中編小説向け・章構成重視
5. 長編小説向け・目次／章扉付き
6. 随筆・エッセイ向け
7. ノンフィクション／ドキュメンタリー向け
8. コラム・評論向け
9. 横書き一般文書型
10. 写真・挿絵を多用する作品向け

## Wordテンプレート共通の完成ルール

テンプレートはレイアウト・書式・スタイルの器としてのみ利用します。テンプレートに含まれるサンプル本文、タイトル、章題、目次、日付、著者・発行者情報、キャプション、見本画像、ページ番号の見本値などは完成作品へ残しません。完成版には作成した作品に対応する内容だけを表示します。

ブラウザで `index.html` を開くか、GitHub Pagesで公開して利用してください。
