# アニメーション表現リファレンス

v1.5.1では、ショート動画の映像表現を考えるための参考候補を `animators.js` で管理しています。

## 使い方

フォームでショート動画を選ぶと、「アニメーション表現の参考」が表示されます。表現ジャンル、国内／海外、名前検索で絞り込み、1名を選択できます。「指定しない／おまかせ」または自由入力も利用できます。

選択された人物名は制作方針の整理にだけ使い、実際の画像・動画生成プロンプトでは、登録されている一般的な特徴へ変換して使用します。既存作品のキャラクター、背景、特徴的な構図や固有の画風をそのまま再現するための指定には使用しません。

## 登録ジャンル

- 日常・人物演技
- キャラクター演技
- アクション・躍動
- 映画的・リアル
- 幻想・冒険・情景
- 光・背景・情景
- 心理・映像編集
- メカ・緊張感
- 実験・デフォルメ
- 実験・抽象
- 風刺・ミニマル
- コメディ・カートゥーン
- 影絵・シルエット
- 絵画・詩情
- ストップモーション
- 物語・リミテッド

## 登録数

国内21名、海外20名、計41名。

候補を追加する場合は `animators.js` に `id / name / region / genre / traits` を追加します。
