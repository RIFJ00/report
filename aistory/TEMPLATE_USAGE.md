# TEMPLATE USAGE — v1.5

1. 完成形式・作品種類を選びます。
2. テンプレートカードの「おすすめ」を参考に、Word原本を1つ選びます。
3. 制作依頼文と選択したDOCXを同じチャットへ添付します。
4. 本文完成後にDOCXへ流し込みます。
5. 原本のサンプル内容はすべて新作へ置換・削除します。
6. DOCXを全ページレンダリングし、サンプル内容が0件であること、空白ページや崩れがないことを確認します。


## v1.5.3 の初期選択

Word成果物を使用する場合は `12point.docx`（小説・縦書き12pt・本文重視）をデフォルトとします。「すべてクリア」後も同じテンプレートに戻ります。
