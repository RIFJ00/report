# 企業宛参考資料セット作成 v1.2

v1.1の表紙PDFで英字・日本語の字形が欠ける問題を修正した。日本語フォントを部分的に切り出す処理をやめ、文字を保持する埋込み方法へ変更している。

## １つのPDFから利用できる

| 選択するPDF | 出力 |
|---|---|
| 企業資料だけ | 表紙＋企業資料の全ページ |
| 会議資料だけ | 表紙＋会議資料の全ページ |
| 企業資料と会議資料の両方 | 表紙＋企業資料の全ページ＋会議資料の全ページ |

会議資料だけの場合は、送付先企業名を手入力する。表紙タイトルは入力した企業名を使い、「企業名様参考資料」となる。未添付の資料は、表紙の収録内容やページ数に表示しない。

## 利用手順

1. `index.html` をブラウザーで開く。iPadはGitHub Pagesの公開URLをSafariで開く方法を推奨する。
2. 企業資料・会議資料のどちらか１つ、または両方のPDFを選択する。
3. 企業名・会議名・説明文を確認する。会議資料だけの場合は送付先企業名を入力する。
4. 必要なら修正し、「表紙を更新」を押す。
5. 「PPTX・PDFを作成」を押して、完成ファイルを保存する。

PDFを１つ以上読み込むと、作成ボタンが有効になる。資料を外すときは「企業資料を解除」「会議資料を解除」を使う。

説明文は、資料の見出し・主要語を使う定型文による自動入力。企業資料だけ、会議資料だけ、両方の３通りに合わせて変わり、画面で自由に修正できる。

## GitHub Pagesの更新

このZIPを展開し、中の `index.html` を既存リポジトリの `index.html` に上書きする。公開後、画面下の「Web版 v1.2（文字欠け修正・PDF１つから対応）」を確認する。古い画面が残る場合は、公開ページを再読込みする。

新規公開の場合はリポジトリの一番上に `index.html` を配置し、「Settings」→「Pages」で、Sourceは「Deploy from a branch」、Branchは `main`、Folderは `/(root)` とする。

v1.2も必要な処理とフォントをHTML内に収録しているため、実行に `assets` フォルダーは不要。旧版の `assets` が残っていても影響しない。単体ダウンロード用のHTMLも同じ内容である。ファイル名が旧版と同じでも、画面内の版表示がv1.2であれば修正版である。

## 確認した範囲

企業資料１ページ、会議資料２ページを使い、企業資料だけで２ページ、会議資料だけで３ページ、両方で４ページのPPTX・PDF生成を確認した。保存したPDFを画像化し、英字・日本語のタイトル、説明文、作成者表示が欠けずに描画されることを確認している。

会議資料だけから両方へ追加する操作、および両方から片方を解除する操作も確認している。生成PDF本文の文字・外部URLリンクは元資料の内容を保持する。

検証用ブラウザーはローカルの `file:` URLにアクセスできないため、単体HTMLのファイル直接起動そのものは未検証。HTTP表示で確認している。iPad実機での保存も未確認。

## 表紙・ファイル

- 表紙の企業名入りタイトルは太ゴシック体。「政策リサーチ」という見出しは入れない。
- タイトル下に説明文、右下に「作成者:一般社団法人日本みらい研」を表示する。
- 長い企業名は、企業名＋様と「参考資料」の２行に分ける。
- PDF表紙の文字は文字として保持し、日本語フォントを埋め込む。埋込み対象が増えたため、PDFは数MB程度大きくなる。
- PPTX表紙は文字を編集可能。本文はPDFのページ画像として収録する。元の縦横比を保つ。
- 合計80MB・60ページまで。OCR・生成AIのAPI・資料内容の事実確認・作成履歴保存は含まない。
- 作成処理はブラウザー内で完結し、資料を外部へ送信しない。

同梱ライブラリー・フォントのライセンスは、`THIRD_PARTY_NOTICES.md`、`LICENSES` およびHTML内のライセンス情報に収録している。
