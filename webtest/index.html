使い方ガイド

基本的な使い方

  • 上部のボタンから「会議等概要説明動画」または「政策レポート等解説動画」を選択します。
  • 自動的に動画リストが読み込まれ、左側のプレイヤーで再生が始まります。
  • 動画が終わると、リストの次の動画が自動的に再生されます。
  • 手動で最新の状態に更新したい場合は、赤い「更新」ボタンを押してください。

動画の検索機能

  • 右上の検索ボックスから、動画のタイトルや概要に含まれる言葉で検索できます。
  • 複数の単語を空白（スペース）で区切って入力すると、すべての単語を含む動画に絞り込めます（AND検索）。
    例: 経産省 補助金 と入力すると両方を含む動画が表示されます。
  • 「経産省」「国交省」などの略称で入力しても、正式名称（経済産業省など）として検索ヒットします。

データ・高度な設定

  • 取得した動画リストはシステム内に蓄積され、過去の動画も検索・視聴可能です。
  • 「API設定」からご自身の YouTube API キーを設定することで、より安定して全件の動画データ（非公開リスト含む）を取得できます。

YouTube APIキーの取得手順（無料）

  1. Google Cloud Console にGoogleアカウントでログインします。
  2. 画面上部のプロジェクト選択メニューから「新しいプロジェクト」を作成します。
  3. 左側メニューの「APIとサービス」＞「ライブラリ」を開き、「YouTube Data API v3」を検索して「有効にする」をクリックします。
  4. 左側メニューの「認証情報」を開き、画面上部の「＋認証情報を作成」＞「APIキー」を選択します。
  5. 発行された AIzaSy... で始まる文字列をコピーし、本ツールの「API設定」欄に貼り付けてください。
