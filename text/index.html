無料のAPIキーを取得する方法

  1. Google AI Studio にアクセスしログインする。
  2. 「Get API key」または「APIキーを取得」「APIキーを作成」などをクリック。
  3. 「Create API key in new project」等を選択して作成。
  4. 生成されたキーをコピーし、上の入力欄に貼り付けて保存。

※この機能はGoogleの生成AIモデル「Gemini」を利用しています。
※APIキーはブラウザ内にのみ保存され、外部には送信されません。
