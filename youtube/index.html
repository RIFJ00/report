使い方ガイド

基本的な使い方

  • 上部のボタンからカテゴリを選択すると、動画リストが読み込まれ再生が始まります。
  • 動画が新たに追加・更新された際、ボタン内の更新日時が赤色で強調表示されます。
  • 手動で最新の状態に更新したい場合は、右側の「更新」ボタンをクリックしてください（管理者用）。

高度な設定 (管理者用)

  • 「API・データ設定」から YouTube API キーを設定することで、より安定して動画データを取得できます。
  • 蓄積されたデータを消去し、現在のYouTube上のリストと完全に同期（上書き）することも可能です。
