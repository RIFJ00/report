# 政策リサーチ 企業宛資料セット自動作成 v1.0

企業資料PDFと会議資料PDFの２つを選び、説明文入りの表紙を付けたPPTX・PDFを作成する。複数ページの資料は全ページを収録する。

## 使い方（Mac）

1. ZIPを展開する。Python 3.10以降が必要である。
2. `start_mac.command` をダブルクリックする。初回は必要なライブラリーを自動導入する。
3. 開いた画面で「企業資料」「会議資料」のPDFをそれぞれ選択する。
4. 企業名・会議名・説明文が自動入力される。必要に応じて修正する。
5. 「PPTX・PDFを作成」を押し、ファイルを保存する。

初回に実行権限がない場合は、ターミナルで次を実行する。

```bash
cd /展開したフォルダー/RIFJ_Cover_Auto_v1
chmod +x start_mac.command
./start_mac.command
```

Anaconda等の既存環境で起動する場合は、次の方法も利用できる。

```bash
python -m pip install -r requirements.txt
python app.py
```

Windowsは `start_windows.bat` を起動する。ブラウザーが自動で開かない場合は、起動画面に表示されるURLを開く。終了はターミナルでControl+C。

## 出力

- PDF: 表紙＋企業資料の全ページ＋会議資料の全ページ。
- PPTX: 同じ順序。表紙の文字は編集できる。添付PDFの本文は高解像度画像として配置するため、本文の個別の文字・図は編集できない。
- 表紙のみのPDF・PNG、および上記をまとめたZIP。

表紙タイトルは「（企業名）様参考資料」。右下は「作成者:一般社団法人日本みらい研」。説明文はタイトルの直下に配置する。

PDF本文の文字・図形・ページサイズ・出典表示を保持し、元PDFに存在するリンクも結合時に引き継ぐ。PPTX本文はページの縦横比を維持し、切り落とさずに16:9のスライドに配置する。入力PDFの内容や記載事実を検証・更新する機能は含まない。

## 自動入力の範囲

企業資料の見出しから企業名、会議資料の見出しから会議名を抽出する。企業資料に実際に現れる主要語を選び、定型文に組み合わせて説明文を作成する。生成AIのAPIや外部サービスへの送信は使用しない。

任意の形式のPDFすべてで正しい企業名を保証する仕組みではない。見出し形式が異なる場合や複数社を含む資料では、企業名・会議名・説明文を画面で修正する。画像のみのPDFでは文字を抽出できないため、OCR済みPDFを利用するか、表紙の情報を手入力する。

添付のトヨタ自動車資料１ページと会議資料２ページを用いた場合は、表紙を含む全４ページになる。

## 処理と保存

処理は起動したパソコン内で行う。PDFは外部に送信しない。起動中の一時ファイルはアプリ終了時に削除するため、必要な完成ファイルは画面の保存ボタンから保存する。入力元ファイルは変更しない。各PDFは100ページ、合計150MBまで。

## コマンドからの利用・既存プログラムとの連携

```bash
python builder.py 企業資料.pdf 会議資料.pdf --output 完成資料
```

任意に `--company "送付先企業名"`、`--meeting "会議名"`、`--description "説明文"` を指定できる。既存の営業文面作成プログラムからは `builder.build(company_pdf, meeting_pdf, output_dir, overrides)` を呼び出せる。

今回の納品物は独立して動作する追加機能であり、既存の営業文面自動作成プログラム本体や公開サイトへの組込みは行っていない。

## このチャットで繰り返し作成する場合

`ChatGPT_作成指示.md` の指示文とともに企業資料PDF・会議資料PDFを添付する。今回と同じ構成・表紙ルールで作成を依頼できる。指示文だけでファイルが自動実行されるわけではなく、ChatGPTが各回のファイル作成処理を行う。
